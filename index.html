License Visualization Assignment

Plot 1

This chart shows the overall distribution of different license types in the dataset. The goal is to get a quick sense of which license types are more common and how they compare to each other.

For encoding, the x-axis shows License Type as a nominal variable since it represents categories, and the y-axis shows the count of licenses as a quantitative variable. The height of each bar represents how many licenses fall into that category. Color is also mapped to License Type, which helps make each category easier to distinguish visually.

A categorical color scheme is used because License Type is a discrete variable with no natural order. Using different colors for each category makes the chart easier to read and compare. A continuous color scale would not make sense here since the data is not numerical.

In terms of data transformations, the chart uses aggregation to count how many records fall into each License Type. This simplifies the raw dataset and makes it easier to compare categories instead of looking at individual entries.

Plot 2

This chart shows the distribution of the top license types for a selected year. It helps users see how the most common license types change over time by focusing on one year at a time.

For encoding, the x-axis represents License Type as a nominal variable, and the y-axis shows the count of licenses as a quantitative variable. Color is again mapped to License Type to help separate the categories visually. The bars are sorted by count so it’s easier to see which license types are most common.

A categorical color scheme is used because License Type is a set of distinct categories. Each type gets its own color so users can quickly tell them apart. Since we are comparing categories rather than showing a range of values, a categorical color map works best here.

For data transformations, the dataset was grouped by both year and License Type, and counts were calculated using aggregation. Then, only the top 10 license types were kept to avoid having too many bars. The chart also filters the data based on the selected year, which allows the visualization to update dynamically.

Interactivity

This chart includes a dropdown menu that lets users pick a specific year. When a year is selected, the chart updates to show only the data for that year. This makes the visualization much easier to read because it avoids showing too much information at once. It also makes the chart more interactive and allows users to explore how license distributions change over time in a simple way.
